# Semantic-addressed world-model benchmark

`benchmark_freeze.json` freezes the paired R2 benchmark design before any
model-family tuning. It defines denominators, split isolation, the ablation
ladder, efficiency/retrieval/prediction metrics, promotion targets, and the
zero-tolerance safety floors. It contains no benchmark results.

Results produced by implementation tasks belong under the configured runtime
or release-evidence paths and must bind the exact manifest digest, source and
environment identities, admitted corpus/checkpoint lineage, commands, and all
failed, unavailable, escalated, and human-reviewed attempts. DuckLake may hold
a rebuildable non-authoritative history projection; DuckDB + Quack task and
receipt authority and final world-root verification remain separate.

No result may claim savings by changing the task population, hiding failures,
weakening validation, omitting human or proof cost, using leakage, or treating
simulation as live execution.
