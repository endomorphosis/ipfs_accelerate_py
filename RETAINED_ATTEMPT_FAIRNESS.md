claim receipt matches, and whose exact coordination claim is already expired.

pause check. Missing history, accepted leases, identity/revision drift, incomplete

still refuse. Direct generic reconciliation keeps its original refusal.

Only that canonical task ID is excluded. Normal dependencies, strict sharding,
claim protection, source/task/workspace admission, provider idempotency and
validation remain in charge of any different task. The old attempt is not
terminalized, requeued, retried, refunded, re-aliased or treated as non-dispatched.

after restart; reconciliation is never permanently suppressed.

custody observation and requires the same authenticated owner/pause reply.
It does not send a `preclaim` acknowledgement while unresolved work remains.

canonical ID is excluded. The ordinary wire format and every owner
credential/source/peer/freshness check stay unchanged. The final pass report
includes the retained UNKNOWN obligation.
