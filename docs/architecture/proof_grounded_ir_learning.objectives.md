# Proof-Grounded IR Learning Fabric Objective Heap

This objective heap is the durable intent for `ProofGroundedIRLearningFabric`.
The companion task board is the schedulable projection. A drained task board,
lower training loss, a model claim, or a provider receipt does not complete an
objective without fresh content-bound acceptance evidence.

## PGIR-G000 Qualified proof-grounded bidirectional learning fabric

- Status: active
- Parent:
- Priority: P0
- Goal: Improve the existing compilers and decompilers among legal/policy source text, typed syntax, canonical IR, `DomainLogicSlice`, existing logic-family representations, prover syntax, controlled natural language, and proof/tactic/counterexample/translation traces.
- Ownership: `ipfs_datasets_py` owns semantic and training meaning; `ipfs_accelerate_py` owns campaign execution and resource control.
- Non-negotiable distinction: syntactic reconstruction, structural reconstruction, semantic preservation, proof preservation, latent similarity, and model confidence are separately represented and evaluated.
- Authority: only canonical deterministic validation and independently checked evidence can advance semantic/proof gates; models, Lean-capable providers, tacticians, hammers, ATPs, SMT solvers, and model checkers produce candidates unless a declared independent authority accepts them.
- Acceptance: all PGIR-G010 through PGIR-G110 children have fresh current-input evidence; no source-lineage leakage; one canonical bridge; deterministic baseline measured; proof-aware pair/loss/evaluation contracts; resumable resource-aware campaign; deterministic promotion or documented no-go; append-only qualified publication only when authorized.
- Non-goals: no new logic family, semantic-state system, canonicalizer, supervisor, proof cache, theorem prover, MCP++ profile, GUI, legal advice, filing authority, or loss-only production authority.

- Parent: PGIR-G000
