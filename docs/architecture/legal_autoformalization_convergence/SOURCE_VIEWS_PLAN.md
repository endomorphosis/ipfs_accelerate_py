# Versioned source views, occurrences and producer lineage

This continuation specializes original LAC-011, LAC-024 and LAC-044 after the
completed producer-provenance and official-source-custody phase. The original
full plan, completed campaigns and historical failures remain frozen. Its three
independent deterministic jobs each own one disjoint result and use zero provider
tokens while retaining native proposal, merge and terminal-fencing machinery.

The first job qualifies a new additive markup view of all ten retained GovInfo
HTML bodies, independently selected as 2024 comparisons. The parser preserves
admitted headings, table cells, body paragraphs, notes, declared fields and every
admitted body text event in DOM order. Balanced markup and strict encoding are
explicit profiles; refusals remain complete named observations. Source, decoder,
raw-body, descriptor, view-version and full-report pins bind exact replay.

The second job retains all twenty physical records from both selected span-cache
files and all comparison document reports. It enumerates every literal overlapping
occurrence and region intersection, retaining zero, repeated and missing outcomes.
New selectors belong to a distinct versioned coordinate system and cannot pass
legacy statutory-source validators. A single match is still unselected. Matching
legal IDs or substrings does not establish the producer's original source, edition,
revision, occurrence, governing context or legal meaning.

The third job independently regenerates complete physical-row provenance and
reconciles a closed, independently pinned producer-witness population. Observed
historical artifacts and matching authored projections remain distinct evidence.
Witness metadata and model declarations do not validate generated legal meaning.
Detached upstream decoder, actor-ranking and supervisor-contract checks qualify
executable behavior only, without training a model or authorizing corpus promotion.

Existing phase7 APIs receive no edits in this continuation. The newly merged
strict-encoding decoder is separately pinned and its historical v1 report
compatibility is recorded as evidence rather than assumed. Original phase7
branches, reports and source identities remain available unchanged.

Each job now binds its exact local interpreter, dataset pytest configuration,
dependency roots, active distribution metadata, module origins and curated file

envelopes so each native result stays below the unchanged proposal file limit.
Validation bounds decoded allocation, checks the entire canonical report and
compares it with its independently pinned full baseline. Compression does not
omit rows, document regions, occurrences or unresolved evidence.
