# Proposed legal graph aggregation

This bounded continuation implements preparatory parts of LAC-040, LAC-044 and
LAC-045 in the frozen convergence plan. It builds on the completed inventory and
preprocessing qualifications. None of these original tasks is fully accepted.

The datasets branch incorporates the October 13 temporal-attention iteration
before graph implementation. Its retained training evidence is audited separately;
the graph layer cannot turn a model score, legacy sealed status, source locator,
or caller declaration into reviewed legal meaning.

The three parallel subgoals are typed source-bound proposals, ingestion through
the existing EntityCache owner, and reverse dependency invalidation. Production
code is committed and pinned before native qualification. Each deterministic job
runs its disjoint reviewed test population and writes one immutable result. The
native supervisor owns task selection, worker worktrees, proposal validation,
serialized merges and terminal cleanup. Independent replay follows native STOP.

All graph assertions remain proposals. Source identity includes physical occurrence
and revision; concept identity includes explicit legal scope. Ordered AST structure
must survive graph conversion. Pending, unsupported and ambiguous inputs retain
dispositions. Missing dependencies prevent a current-closure claim. Reverse
invalidation concerns the supplied dependency inventory, not global legal truth.

Accepted entity resolution, definition interpretation, exhaustive corpus coverage,
semantic consistency, doctrines and Lean theorem admission remain downstream
work requiring their original review, context, evaluation and toolchain gates.

The pinned entity-cache Parquet footer reports 1,960,876 rows in 16 row groups;
these are index rows, not a count of reviewed entities. Its materialized graph
schema is distinct from EntityCache's work queue. This campaign qualifies explicit
typed occurrence ingestion into proposals; direct legacy/Hugging Face bulk
backfill and source-position reconciliation remain downstream work.

The qualification population contains 22 new graph cases, 16 new adapter cases,
18 new invalidation cases, 90 existing EntityCache compatibility cases and 19
detached contracts for the latest attention adapter. Those 19 source contracts
exercise inert routing and analytic fixtures; they do not execute model tensors.

The latest retained temporal-attention candidate did not improve fresh whole-IR
outcomes (0/36 on both panels). Its separate pinned audit preserves denominators,
training exposure, checkpoint lineage and the actor-boundary next-experiment
proposal. No new training or checkpoint promotion occurs here.

Execution uses the existing shared scheduler policy without cap changes. No model
training, model provider invocation, corpus publication or external service write
is part of this campaign. Earlier frozen checkouts and failed attempts are retained.
