## Repairs and integration

The native START timeout was traced to daemon initialization recursively scanning
ambient legacy database directories before publishing its first heartbeat. The
isolated admitted runtime now signs and uses an explicit run-local orchestration
directory. Production migration defaults, independent admission and the 30-second
health deadline are preserved. A real START/STOP regression published the live
owner heartbeat about 0.65 seconds after daemon entry.

The datasets source owner now joins immutable captures, persistent AST rows and
current structural heads. Bounded paged staging preserves full committed
inventory, resumable native SQL cursors and explicit opaque/deferred entries.
Removing repeated whole-manifest CID computation and caching parsed summaries
after exact byte checks eliminated the dominant measured cost. Fresh-process
replay, corrupted/missing bodies, eviction and classifier-producer changes remain
checked. This staging profile does not publish a partially built complete head.

Doctor root invalidations, tombstones, quarantine and receipt observations now
survive native file-backed restarts. Proof discovery has bounded keyset pages.
A cross-package bridge retains all 16 canonical key dimensions, source identity
and supervisor execution context. This bridge grants no positive proof authority:
a separately verified obligation link remains necessary. Quack transport also
needs a typed transactional control command before durable Doctor control can be
qualified there. Those unsupported operations fail closed.

The new datasets CodebaseIR generation envelope retains exact shared parent
weights and uses the unchanged SecurityIR structured decoder and ridge fitting
modules. It freezes source splits, binds real numerical children to source/target
manifests, enforces bounded workers and validates target-free inference. It keeps
the existing LegalIR and other domain checkpoints intact. The failed retention
result is preserved and blocks any claim of an improved repository model.
