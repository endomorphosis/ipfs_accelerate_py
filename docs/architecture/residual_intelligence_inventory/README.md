# Verified Residual Intelligence Foundry baseline inventory

This directory is the immutable, current-source prerequisite and residual-call
inventory for `agent-supervisor-verified-residual-intelligence-foundry-v1`.
Findings bind to `origin/main` commit
`b8a6950a1cae32ca25e007f76984e818fc5d38a2` and tree
`9d966a4f8d4763a1877e4d419f9e11c935559871`.

The records deliberately distinguish source availability from qualification.
A task-board status, similarly named class, historical receipt, or importable
module is not qualification evidence. Missing optional authorities constrain
their integrations; they do not block independent contracts and data work.

- `baseline.json` records repository, dependency, provider, model-serving, and
  hardware observations.
- `prerequisite_matrix.json` records every named prerequisite with exact source,
  schema, test/proof evidence, environment, and disposition.
- `pgir_training_gate.json` preserves the current PGIR no-go as a mandatory
  `training_unavailable` gate.
- `corpus_construction.json` distinguishes implemented builders and small
  synthetic contract fixtures from an admitted training corpus.
- `residual_model_call_inventory.json` identifies committed provider/model call
  surfaces without inventing trajectory rows that do not exist.

None of these records grants authority, accepts a proof, promotes a checkpoint,
or marks a task complete. Current-tree tests and admitted independent producers
remain required.
