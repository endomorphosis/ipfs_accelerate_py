# Historical native bootstrap proposal

This directory preserves the exact 67 authored source, test, fixture, design and
engineering evidence files from accelerator commit
`8e02f9bed9f2a84a5a5245f90b0775ae1e806260`. The historical `READINESS.md`,
failures, task identifiers, source pins and receipts are retained unchanged.

These files are documentation and a proposed implementation, not an installed
runtime. Runtime installation, productive dispatch, outstanding fault and
cancellation qualification, and legal/model/Lean acceptance remain unresolved
as stated in the historical readiness record. Preservation does not rerun or
requalify the archived controls and grants no current execution or resource
authority. No helper, fixture or archived test was imported or executed during
this preservation.

Current operational owners remain the maintained modules under
`ipfs_accelerate_py/agent_supervisor/runtime/`,
`ipfs_accelerate_py/agent_supervisor/todo_daemon/`, and
`ipfs_accelerate_py/agent_supervisor/rescue/`. Consult their current tests and
admission procedures before adapting this proposal. Do not execute the archived
requests, install their proposed owners, restore old source pins, or broaden
resource budgets by following this snapshot.

The source-preservation manifest records exact Git blob identities, SHA256
hashes, sizes and modes. Preservation checks parsed the 23 Python files as ASTs
and screened all 67 files for common credential patterns. Those static checks
are not runtime, native resource, scientific or statutory-semantic validation.
