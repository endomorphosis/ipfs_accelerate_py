# Dual-board report freezer V04

This additive source proposal builds on qualified report-freezer-v03, whose actual Git component passed 13 cold controls, 11 Git cases/29 commands and a separate inert custody probe. It preserves the qualified `_Git` anchor topology, `GitCustodyPending`, `acknowledge_stopped_git_custody`, counter guards, report-only staging and original shared commit tail. Author performed source reads, AST/hash checks and source authoring only: no imports of this helper, tests, Git, native, Docker, provider or GitHub jobs.

The authoritative board remains `daemon.todo_path` beneath the original canonical `daemon.repo_root`. Its relative path is derived from those actual objects. The workspace comes only from the original active managed lifecycle associated with that repository and actual process birth. The workspace board copy is derived from that relative path. Both copies must retain the exact normative SHA and bytes; task parsing, all 64 identities/frontier, manual completion and canonical CID/key remain bound to the authoritative board. No method accepts a replacement board or baseline and no code assigns `daemon.todo_path`.

The original daemon exposes three delegates, already composed in root daemon-integration-v02:

- `preflight_report_only_candidate(state, *, task, preflight_owner, parent_phase, control_plane_connection, protected_source_sha256, declared_external_storage)` stores a private layout only after its actual readonly anchored Git session stops; returns inert facts with `attempt_consumed=False`.
- `report_only_preflight_storage_roots(state, *, task)` derives exact roots from actual `.git`/`commondir` metadata before native precharge; it creates no child or grant.
- `report_only_preflight_workspace(state, *, task)` rechecks original captured objects, board copies, refs/index and counters before returning the derived workspace for explicit invocation construction.

The host supplies an actual same-PID 3 CPU/4096 MiB/16-slot parent phase and fresh 1 CPU/at least512 MiB/4-slot preflight owner beneath it. It precharges roots using the unchanged `storage_charge_key` API before the first Git child. Preflight checks the shared common-Git repository relation, aliases/indirections, tracked modes, hidden index flags, submodules, existing dirt/index, native storage bounds and the baseline board blob. The baseline is discovered by the actual native Git session. Unsupported layouts refuse before ordinal consumption. The host alone finalizes/releases the stopped short-lived preflight owner; it cannot reuse that owner's history as the callback freezer owner.

The original `_mark_implementation_started` calls `capture_before_attempt` before changing state, passing its actual `worktree_path` and `branch_name`. The helper rechecks readonly HEAD/loose-or-packed-ref and index snapshots before that mutation. `capture_dispatch(daemon,state,task,attempt,invocation,control_plane_connection)` accepts no caller workspace or baseline and joins the original preflight, identical explicit invocation/cwd and original borrowed connection. Both board copies and repository/lifecycle identity are checked throughout freezing. Snapshot checks are necessary observations, not a claim of hard filesystem immutability or elimination of all concurrent-change windows.

All SELECTs require candidate's public `require_borrowed_task_state_connection` API, which authenticates the registered original same-PID/thread/target object. This module never opens, reconnects, closes or migrates the state database. Operational qualification requires the separately frozen borrowed-state, actual host, H4 callback and composed daemon source closure. Those dependencies are not replaced by historical JSON, copied dataclasses, fake native owners or source test projections.

Exactly47 new cold/source cases are authored. `qualify_board_controls.py` is finite source for a separate actual V05 generic owner (1 CPU/8 slots), storing only private result/JUnit files. The outside request template is deliberately nonexecutable until root binds the actual manifest and full V05/SDK closure. No cases have been run by the author; runtime qualification remains pending. Existing 13 anchor tests and actual Git campaigns are not rerun by this worker.

Its positive layout must exercise original authoritative board plus workspace copy/baseline blob; negatives must cover board drift, wrong repo/lifecycle/common relation, hidden flags, gitlinks, extra dirt, refs/index drift and inadequate precharge before any original counter write. This source bundle does not claim such a fixture passed or authenticate a provider success.
