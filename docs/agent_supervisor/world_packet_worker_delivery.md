# Authenticated worker packet delivery and local accounting

`terminal_world_worker_packet_experiment.py` qualifies a finite owner-to-worker
packet boundary in the operator's existing pinned offline container. It creates
three independent authored cases with one, four, and eight inert functions in a
single selected file. It does not execute those functions, call a provider,
train a model, run native validation commands, or complete a task.

The native typed task claim, SQL business projection, Portal allocation, Git
lifecycle, source session and context compiler are genuine. Their inherited
`FakeQuackTransport` and deployment fixture metadata remain authored; this is not
qualification of TCP transport or a shipped Terminal Bench dispatch route.
The root operator supplies the existing host resource lease, cached immutable
image, read-only pinned source/dependency snapshots, real UID1000/1001 accounts,
and an exact root-owned, no-arguments sudo grant for the fixed worker wrapper.
The container-local scheduler accounts for its native fixture only; it is not a
second host resource ledger. No dependency install or network request is needed.

The native task projection retains scalar business fields and complete output,
dependency, acceptance and validation rows, including unknown JSON fields. Its
explicit administrative omissions are timestamps and the top-level completion
receipt; original rows are separately pinned by the owner. The literal public
projection binds the initial native assignment. The owner transitions only the
allocated root from 0700 to 0750, then captures the source session and compiles the
packet. Compilation before that transition is refused because source root mode
is part of custody. The old assignment and allocation remain stale.

Every packet requires the byte-identical native task reference, selected raw
source reference and three authored intent/security/UI constraints. These are
authored obligations, not learned IR inference or legal/semantic truth. Native
structural symbol references are counted separately. This profile declares
`validation_profile='read_only_observation@1'`, effect `repository_read`, no proof
obligations and zero validation commands. It preserves the genuine absence of
native validation commands instead of manufacturing checks.

`RepositoryWorldWorkerPacketDelivery` composes the original transitioned native
handoff, issued compiled binding and real process observer. The literal sudo
launcher is registered before the descriptor reaches the child. The fixed
worker imports the delivery client directly and receives exact packet text over
the bounded authenticated Unix channel. Actual SO_PEERCRED UID/GID, PID birth,
ancestry and command-line checks bind the GET and digest ACK to the same worker.
The worker's stdout exports only bounded receipts. A later native task-body
change is refused while that worker is still alive; stale state never falls
back to raw context. The experiment restores its own fault before native fixture
teardown, reaps its child and stops both services before cleanup.

The broker grants no SQL interface, source-get operation or completion authority.
The 0750 transition does grant filesystem group read/search; it does not prove
kernel cwd, deny all filesystem source access, or qualify full container
containment. `worker_workspace_verified`, world dispatch, model ingestion,
compiler signature, proof, execution and completion flags remain false.

The comparison uses the same complete native projection, selected literal raw
source, required references and core declarations. The raw-inline arm is an
offline authored baseline only: the live service always sends the compiled
packet. The actual router renderer supplies identical workspace advice to both
arms. The complete initial text and the same descriptor-discovery guidance,
literal commands and actual helper receipt lines are measured once per arm.
Protocol-to-model display is unknown. Packet bytes already included in initial
text are not charged again; binary IPC frames and private storage are separate
metrics. GET, ACK and stale refusal produce an exact three-response service
census with canonical body and four-byte framing totals.

The optional hash-verified cached `o200k_base` ranks and installed tokenizer
produce exact local encoding counts for these strings. They remain a provider
proxy: model framing, provider cache billing and native provider usage are
unknown. Missing tokenizer counts are null, not zero. Reports retain smaller,
not-smaller and unavailable outcomes; no efficiency improvement is forced.
The disposition compares initial rendered prompts; complete authored trace
counts are separately retained and do not establish whole-session savings.
`offline_comparison_disposition` never selects a live model route. No measured
provider cost or whole-session saving is claimed.

Root runs `run_experiment(scratch_root=..., tokenizer_cache=...)` only after its
native leased qualification. Each sequential case uses a separate bounded
128MiB private fixture; successful cleanup removes held-root contents while
retaining its empty private shell. Failed or uncertain native contexts preserve
scratch and later cases remain explicit not-attempted records. The report
contains only listed source-file hashes, counters, dispositions and kernel peer
metadata. `validate_report(..., expected_report_sha256=...)` requires an
independent full canonical report pin and checks closed populations, arithmetic,
scopes and false authorities. It does not replay native operations or make its
own seal an authenticity claim. The operator records actual qualification and
container/dependency/tokenizer provenance outside the source report.

## Planned next goal: remove repeated model-facing data

This is a proposed next stage, not implemented by the delivery qualification.
The target is the admitted packet's presentation, preserving its complete
business/source facts and native custody. It does not assume a reversible
minification of arbitrary repositories.

The current renderer repeats the complete task in `task-text` and in the native
task reference's summary. `compile_core()` additionally carries task, output,
dependency, acceptance and validation data as canonical JSON strings. Each
selected reference adds its full record inside another evidence/member wrapper:
IDs, digests, kind, summary and path occur at multiple levels. Repository/tree,
policy and scope bindings appear in the packet header, compiled authority and
reference records. JSON strings embedded inside JSON add quoting overhead.
These sites are explicit in `runtime/repository_world_worker_packet.py`,
`runtime/repository_world_packet.py`, `runtime/repository_context_compiler.py`
and `prompt/delta_task_packet.py` under `ipfs_accelerate_py/agent_supervisor`.
Some repetition also exists in the baseline; the current measurements do not
provide a causal token attribution to individual fields.

1. **Subgoal: establish an exact content census.** Inventory each repeated body,
   role and custody field in the same three complete inputs. Measure candidate
   changes using complete rendered prompts and authored traces. Classify only
   explicitly reviewed transport/hash fields as host custody; preserve every
   business field, selected source byte, effect/path restriction, instruction
   and unknown/open obligation.
2. **Subgoal: add a bounded, versioned presentation.** Retain the fully validated
   native packet and independent pins in an owner sidecar. Render task and source
   bodies once, with explicit role references and a shared binding header where
   appropriate. Preserve exact literal bytes and all distinct relationships;
   matching labels or hashes alone must not merge roles. Require exact inverse
   reconstruction with the pinned sidecar, refuse inconsistent repeated values,
   and fall back to the existing view for unsupported schemas or absent counts.
   Keep defaults and historical artifact bytes unchanged.
3. **Subgoal: qualify the new view at the real boundary.** Bind its exact rendered
   digest to the original current packet, task and handoff before GET/ACK. Test
   dropped/changed/unknown fields, dangling references, foreign sidecars and
   stale source/task state; stale state must abort. Repeat all three actual
   worker cases and the equal-information comparisons under unchanged limits.
   Keep a view only when measured full-input and authored-trace costs improve;
   retain negative results and distinguish local proxy counts from any later
   native provider usage. Provider savings and general default adoption require
   separate representative workflow evidence.
