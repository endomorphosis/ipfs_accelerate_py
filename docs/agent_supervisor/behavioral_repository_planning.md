# Behavioral repository planning

`planning.behavioral_codebase_match.match_behavioral_intent` joins the native
IntentIR/CodebaseIR catalog, complete semantic inventory and durable finite proof
cache. It emits `intent-codebase-match@2`. The separate v1 routes retain their
existing meanings.

The first profile requires the complete two-clause finite integer instruction.
Exact path/function/parameter/contract discovery nominates source; it cannot
establish satisfaction. Fresh Python observations and a kernel-checked finite
model table supply one bounded type fact and, for the authored fixture, five
offset counterexamples. The model table does not establish Python equivalence.
Unrecognized predicates, arguments and prohibited modality retain every
requirement as unresolved. Missing or corrupt discovery is a refusal, never
evidence of satisfaction or permission for a hidden fallback.

`planning.behavioral_repository_plan.preview_behavioral_repository_plan` creates
`repository-proof-planning-snapshot@2` and passes its exact finite facts through
the existing obligation compiler, candidate planner and critic. The snapshot
contains the complete query and discovery records, source roots, explicit
model-off identity, finite observations, checked cache binding, typed obligations,
reviewed operations, residuals and nonempty provenance roots for every fact.
Both declared operation IDs remain visible even when only the offset operation
is selected as a proposal.

The request's configuration root must be the `plan_revision_cid` of
`repository_evidence_binding(...)`. That helper declares identity, not authority.
The preview independently observes the native source and catalog, rechecks cache
artifacts, and checks producer/configuration identity at policy callbacks. There
is no parameter accepting caller facts, cached matches, model predictions or
static current roots. It performs no training or model inference.

The preview is not a new execution admission profile. It cannot remove signed
tasks, launch a worker, authorize edits or complete a task. The live owner and
tools remain required. Positive cache verification can rerun native checkers;
this implementation makes no claim to avoid checker cost. Deadlines are
cooperative and inherit existing bounded subprocess operations.

Native tests passed: nine matching controls and five final planning controls.
The latter include actual compiler/planner/critic execution, changed source,
wrong configuration, missing selector membership and injected-input refusals.
Raw results, the emitted full snapshot and exact producer hashes are in the
[retained qualification](evidence/behavioral-repository-planning-20261002/qualification.json).
These authored finite fixtures are not a Terminal Bench result or a claim of
general natural-language interpretation.
