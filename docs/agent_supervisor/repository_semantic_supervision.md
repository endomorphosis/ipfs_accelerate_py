# Native semantic-manifest and finite-cache qualification

The existing native finite supervisor driver accepts three independent opt-ins:

```sh
python -m benchmarks.agent_supervisor.container_coding.native_repository_finite_supervision \
  --output /absolute/fresh/run \
  --python /absolute/python --lean /absolute/lean \
  --public-evidence --semantic-manifest --checked-cache
```

`--semantic-manifest` prepares the datasets frozen scan policy and complete
`codebase-ir-manifest@1`. The authored fixture uses a tracked `.gitignore`, so
scope rules are captured source. The complete descriptor is bound into planning
configuration, joined to the selected IntentIR contract, and reconstructed with
live source and ignore-scope checks during root observation. All six inventory
entries remain visible; only the declared scalar function has a semantic model.
Declarations do not become checked facts. After native publication, a separately
opened source owner captures the successor, and a cold rebuild must agree on
the complete semantic unit rows, native artifact references, coverage and finite
observations. Head generations and execution receipts keep their own identities.

`--checked-cache` stores the initial refuted offset contract in the existing
FormalVerificationCache owner plus immutable source CAS. Planning binds and
reconstructs that exact historical record. After repair, the successor has a
distinct full key and a positive finite-table proof record; a newly opened cache
handle must reconstruct it and rerun actual Python/Lean checks. The previous
source head is refused. The fresh matcher remains the owner of current facts.
This conservative cache route measures persistence and reconstruction, and
currently adds checker work rather than avoiding it.

`--public-evidence` carries exact source, assumptions, initial counterexample,
checked candidate records and residuals into the actual worker after semantic
encoding. Independent signed task admission, public validation, publication,
completion and STOP use the existing native machinery. This is an authored
controlled-language finite repair with no model calls. It is not a learned
instruction evaluation, DuckLake qualification or official Terminal Bench score.
The source384 checkpoint qualification remains a separate numerical route.

All opt-ins are disabled by default. The driver reports each phase's actual
evidence and preserves failed runs. Host resource safety remains enabled;
admission refusals must be retained rather than counted as successful trials.
