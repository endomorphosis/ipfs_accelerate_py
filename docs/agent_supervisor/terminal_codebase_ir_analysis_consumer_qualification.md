# TerminalBench full-bank source-analysis consumer qualification

The retained intent-conditioned relevance head now drives an explicit source
inspection iterator. All candidates, both native instruction SourceRefs and all
unknown IntentIR residuals survive the handoff. This is an opt-in benchmark API;
the supervisor's default entry point and symbolic task selection are unchanged.

The [pure consumer](../../benchmarks/agent_supervisor/container_coding/terminal_codebase_analysis_order.py)
replays the independent frozen corpus, current admitted source records and
externally pinned checkpoint/fit identities. It reconstructs the entire
historical metadata projection: sources, AST, syntactic KG, native 44-dimensional
vectors, queries, judgments, split/history, checkpoint, training, rankings,
coverage status and empty contracts. Every native row wrapper, export, family
digest and row packet must match. An exact query binding includes the original
instruction hash, authored-navigation hash, full native document hash, both
SourceRefs and selected navigation statement IDs.

The [file receiver](../../benchmarks/agent_supervisor/container_coding/terminal_codebase_analysis_receiver.py)
reads only declared pinned inputs, consumes the complete function bank in the
selected order, verifies each raw and normalized source span with the native
byte-map checker, then rereads every input before returning success. It does
not import or execute code from the repository under test. Missing, changed,
aliased, incomplete or mismatched inputs refuse before a result is returned.
Late mutations may occur after visits have happened; refusal does not erase
those visits. Currentness covers the recorded observations of admitted files,
with no atomic checkout or whole-repository coverage claim.

**31 focused controls passed**, including Unicode/decorated/nested functions,
same-codebase query swaps, external pin failures, removal of the opaque original
guard, resealed metadata truncation/duplication, an operator edit whose 44 native
feature values remain unchanged, and source/instruction/checkpoint-file changes
during actual inspection. See the [captured test evidence](../../../../artifacts/codebase_ir_terminal_bench/terminal-codebase-ir-analysis-consumer-20261004-01/evidence/tests-04/tests.xml).

The [public inspection](../../../../artifacts/codebase_ir_terminal_bench/terminal-codebase-ir-analysis-consumer-20261004-01/evidence/actual-02/inspection-summary.json)
completed 10 receiver calls and **2,510 function-span visits**. All five retained
development queries used trained order. Bottle header-name also exercised
disabled, model-off, lexical, zero and reverse order over all 358 functions.
Disabled and model-off produced identical original-bank visitation; trained
order differed, while every variant retained the identical source population.
Trained header-name inspected `_hkey` first; lexical inspected `static_file`
first and baseline inspected `_cli_parse` first. Header-value trained order
started at `BaseRequest.__setattr__`; the authored positive `_hval` remains at
its previously observed rank 15. Ranking is diagnostic and can prioritize a
function outside the reviewed focus. Neither scores nor judgments establish
behavior or requirement satisfaction.

The [file-only audit](../../../../artifacts/codebase_ir_terminal_bench/terminal-codebase-ir-analysis-consumer-20261004-01/file-only-audit-02.json)
matched all 4,000 rows in 12 families against separately pinned retained
payloads, full row roots and exports. It independently replayed complete byte
maps and visitation populations. This associates current admitted source and
the head with the previous native DuckDB/DuckLake fresh-process readback.
**No native stores were reopened here**, and no new SQL, hydration, public fit,
autoencoder fit, prover, PlanCreate, task, fact, effect or output was produced.
The synthetic test fixture fitted four epochs in each of two actual admitted
test runs: eight unit epochs total, zero public epochs in this increment.

Failures remain retained. The first test and first public attempt timed out
before acquiring a lease. Historical observations reported memory pressure
above 2%; exact terminal blocking causes remain null. A test run passed 30/31
cases but exposed a fixture alias between original and current source; the
helper was corrected in a separate captured generation without changing the
production API. Another attempt's collection was stopped by the import guard
because the successor runner referenced the old capsule; the corrected runner
then passed all 31 cases. No pressure threshold or safety gate was relaxed.

The six measured producer outers total **102.53240990295308 seconds**, including
all four failed attempts. Owned times are nested and are not added again.
Each admitted attempt reserved one CPU, 2,048 MiB and four child slots under
the unchanged 2/50/10 pressure policy, with 30-second admission and 120-second
outer limits. Both successful roots released and drained. Ninety selected
parent-owned imports matched before/after in the passing tests; 88 matched in
the public receiver run. These are selected import observations, not a census
of all loaders/processes. Full-session CPU, GPU, memory peaks and process counts
are unavailable. Preparation, file-audit and documentation time are outside
the six-producer sum. The [review record](../architecture/repository_proof_index_and_codebase_ir.analysis_consumer_review.json)
retains these boundaries and evidence pins. Final retention is a separate last
writer/readback recorded below the artifact root's `final-retention-01`.

Every original task guard and navigation residual remains unknown. Every
receiver returns an abstained planning handoff and empty tasks/facts/effects.
All 32 repository-proof-index criteria remain OPEN; default activation,
source semantics, generalized ranking gains, asymptotic convergence, learned
logical projections, Lean compilation of this new IR, verified cache hits and
original TerminalBench completion remain unqualified.
