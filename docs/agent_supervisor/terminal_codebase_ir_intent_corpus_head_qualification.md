# Frozen native intent/source corpus and advisory relevance head

The new corpus binds complete initial codebases to native `ipfs_datasets_py` IntentIR and explicit navigation judgments. A separate scratch ranking head learns from four reviewed Bottle pairs. This is a development experiment; the supervisor default remains inactive and all 32 repository-proof-index exit criteria remain OPEN.

## Corpus and fit

The [corpus builder](../../benchmarks/agent_supervisor/container_coding/terminal_codebase_intent_corpus.py) derives all 362 native Python function units: Bottle 358, MNIST 2, HTML filter 1 and terminal interface 1. Every unit retains its source hash, qualified symbol and line, AST hash, decorator-aware byte map, normalized body and 44 native AST features. Repeated definitions at different lines remain distinct. Unsupported inputs refuse or retain an explicit frontier; candidate banks are never trimmed to authored positives.

Five native intent documents retain the complete public original instruction as an unknown opaque guard, plus a separate inferred, machine-authored navigation goal. Ten explicit judgments supply five positives and five reviewed navigation negatives; all other query/function pairs remain unjudged. Both Bottle queries share one train family. MNIST supplies a validation development family; the other two tasks supply test development families. Native query-family and source/body/alpha-shape checks reject cross-role duplicates. Historical Bottle exposure is declared as known lineage, without attesting to global absence of other exposure.

The complete envelope was atomically published, fsynced and read back before fitting: `2a452811f54d85509e2d0b0c962ecab5d8cd221a6cd0321556a387c95da0a8e7`. The [corrected prefit review](../../../../artifacts/codebase_ir_terminal_bench/terminal-codebase-ir-intent-corpus-head-20261004-01/prefit-independent-review-02.json) passed six independent file checks. Its initial failed reader remains retained: it collapsed repeated symbols and compared unsorted input history to canonical output history. The runner binds the reviewed driver, helper and frozen envelope before fitting.

The [ranking head](../../benchmarks/agent_supervisor/container_coding/terminal_codebase_intent_ranker_training.py) fits 80 new parameters from zero with 128 deterministic full-batch gradient steps. Inputs are fixed hashed query/code lexical interactions and query interactions with native AST features. Only the four train positive/negative-navigation pairs drive updates. Validation/test labels do not drive updates, feature normalization or model selection. No previous autoencoder weights or latents initialize this head; no new autoencoder fit ran.

The recorded regularized pairwise objective falls monotonically from **0.693147181 to 0.112718314**, an 83.738% decrease. Gradient norm falls from 0.469747846 to 0.009868923. This is finite numerical optimization evidence. No Lean theorem, asymptotic convergence certificate, learned source semantics or behavioral proof is established.
