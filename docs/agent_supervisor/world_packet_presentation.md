# Opt-in lossless worker-packet presentation

`run_experiment(..., presentation_profile='lossless_model_view@1')` adds an
explicit presentation experiment to the existing three native cases. Omitting
the option preserves the original report fields, source-pin population,
binding metadata, delivery profile and 17 structural checks per case. It does
not enable a default Terminal Bench or model route.

The pure codec prepares a view from the original current compiled prompt. The
owner retains its bounded sidecar, pins both representations and replays the
complete original bytes before binding a view. The benchmark uses the original
native task projection, required literal source and IR obligations, complete
compiler context and identical instructions in every comparison. A codec view
cannot replace source or task freshness checks. Unsupported codec inputs use
the unchanged original, preserving all unknown fields rather than dropping
them. No global repository minification or learned semantics are claimed.

The prelaunch gate uses the verified cached local tokenizer and complete
rendered initial input. It selects the proposed view only when both its UTF-8
bytes and local token count are strictly below both the original compiled input
and the fair raw-inline baseline. Missing token counts, an unsupported codec or
a non-improving comparison selects an actual original binding without the
presentation argument. The report keeps the proposed metrics and the explicit
fallback reason; it never labels an undelivered proposal as worker receipt.

The real worker GET and digest ACK are bound to the exact selected prompt and
same original native handoff. A subsequent native-body fault is refused while
that worker is alive. Stale state aborts, including after a tokenizer callback;
it cannot select an original fallback. Kernel cwd, whole-repository isolation,
model ingestion, execution and completion remain unqualified.

The actual descriptor and GET/ACK/refusal transcript contains identifiers and
peer observations unavailable before launch. After it exists, the benchmark
counts each of the three complete authored traces directly: raw baseline,
original compiled input and proposed presentation, each followed by the same
actual protocol text exactly once. It does not assume tokenizer counts are
additive. `post_delivery.efficiency_qualified` is separate from the structural
report's `qualified`; a negative trace result preserves an actually delivered
view and never invents a retroactive original fallback. Undelivered proposals
remain authored comparisons only.

The opt-in report adds a closed per-case `presentation` observation and a closed
`representation_efficiency_population`. It binds actual delivery to the
selected body, retains exact original inverse and sidecar hashes/byte counts,
and records a whitelist of structural codec census counters. Host sidecar
storage, framed IPC bytes and hypothetical model text are separate. Counter
censuses identify repeated content but do not establish per-field token causes.
Every physical case remains present, including failures and unmeasured cases.
Validation requires the independent full report pin and rederives selection,
trace arithmetic, identity joins and population counts.

Local `o200k_base` counts describe the authored strings exactly and remain a
provider proxy. Provider billing, cache effects, tool-to-model display and
whole-session savings are unknown. Root owns finite qualification under its
existing leased offline container profile, with the same pinned image,
dependencies, accounts, source bounds and sequential private-fixture cleanup.
Default adoption requires positive complete-input and full-trace results plus
separate representative workflow evidence.

## Finite actual qualification

The operator's final-source `docker-v02` run completed three cases and all 17 structural
checks per case. Each case genuinely delivered the presented view to UID 1001,
received its digest ACK, reconstructed the exact original, and refused a later
native-body change. All three prelaunch and post-delivery efficiency gates
passed; there were zero original fallbacks. The full canonical report pin is
`7a0d3f75f538e90a53ad47436ffdbc4b8636780f0e9191057b40e17b9e309ff1`.
Its retained report is
`artifacts/world-packet-presentation-20261014-01/docker-v02/results/measured.json`
under the operator workspace, outside the repository.

Relative to the raw baseline, initial local token counts decreased by 18.14%,

savings. The original task/source custody and false authorities remain intact.

The earlier `docker-v01` observation and its report pin remain retained as
historical evidence. Before the final-source rerun, the inverse decoder was
fixed to copy shared business-row dictionaries before reinstating distinct
per-row custody IDs. Two regression cases cover that aliasing error; normal
view and sidecar byte outputs are unchanged. Final qualification passed 288
distinct pytest cases: 77 codec, 101 report, 64 existing delivery, 27 new native
binding and 19 existing binding cases, plus nine driver checks. This establishes
the scoped reconstruction and delivery checks, not semantic proof.

## Next goal before default adoption

Qualify representative actual task/model workflows while preserving the same
source and business requirements. First, retain a bounded task population with
independent source/requirement pins and meaningful existing acceptance checks,
including unfamiliar business fields and longer dependency contexts. Next,
compare original and presented inputs on the same pinned model route; retain
all tool turns, failures, retries, source retrieval and complete native usage
coverage. Finally, compare task-quality outcomes and full-workflow costs under
the original native safety/freshness gates, retain negative results, and set an
explicit acceptance threshold before any default change. Exact inverse alone
does not establish that a model interprets shared references equally well.
The default remains `presentation_profile=None`; this qualification grants no
model-ingestion, execution, completion or default-adoption authority.
