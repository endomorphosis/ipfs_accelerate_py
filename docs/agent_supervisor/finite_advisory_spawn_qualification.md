# Advisory CodebaseIR artifacts bound to native supervisor launch

The [completed native run](../../../../artifacts/codebase_ir_terminal_bench/finite-advisory-spawn-qualification-20261002-03/native/result.json)

process creation. It also qualifies STOP after advisory drift and exact

[independent audit](../../../../artifacts/codebase_ir_terminal_bench/finite-advisory-spawn-postrestart-20261002/audit-attempt-01/result.json)

The signed worker keeps its existing model-off authority and both original
administrator tasks. No production acceptance row is closed.

The factory validates the current training and frozen contexts, actual model
checkpoint and lineage, mathematical lowering, reviewed/generated proposal
and public handoff. It independently derives mandatory artifact identities
from those validated records. Optional caller pins cannot remove mandatory
files or replace their expected bytes. The signed closure captures persistent
file witnesses, complete selected directory inventories and producer
identities. Its serialized reference supports historical verification; it
cannot construct the live sealed capability required for launch.

`finite-repository-one-ready-advisory-bound-native-worker@1` is an explicit
new profile. Omitting the advisory closure retains the older profile and
producer fieldset. Each native seal in this run contains 265 files, nine
directory inventories and 25 selected producer modules. The bounded profile
permits at most 512 files, 64 MiB per file, 128 MiB total observed file bytes
and 128 KiB for the complete signed document/reference. It rejects aliases,
symlinks, hard links, unexpected directory entries and changes to bytes,
identity, mode or persistent file witnesses.

The last detached check runs under the native owner's lock, after preparation
callbacks and directly before actual `subprocess.Popen`. It verifies the
signed bindings and physical artifacts. It does not fit a model, run numerical
inference, invoke a prover, construct an owner/registry or call a planning
observer. These are cooperative sequential observations, not atomicity against
arbitrary operating-system writes or process-origin attestation.

The fixture changes a frozen checkpoint receipt after the last verified launch
callback. It then runs a separate invocation that replaces the frozen inference
receipt with identical bytes in a different inode. Both actual START operations
refuse before Popen, with zero process births, claims, attempts, publications or
changes to the original task population. Each records a failed native lifecycle
saga and a terminal compensated control transaction: compensation is an explicit
no-op after fresh observation of an empty Linux tree. Only the exact sealed
pre-Popen refusal can take this path. Ordinary launch failures, a created
process and restart failures retain their repair behavior.

Genuine STOP succeeds after each refusal. The owner detaches only its exact
callback and opaque in-memory binding after STOP, empty process observations
and isolated worker-UID cleanup. It refuses active or foreign callbacks.
Handler selection and execution remain within the owner transaction; supported
non-reentrant locks are acquired once. Legacy services retain their plain
four-field dictionary and legacy binding API. The new profile records callback
retirement for both negative invocations and the positive invocation. These
close receipts are historical unsigned runtime observations, not signed
process-origin proofs.

The positive invocation launches the real separate-UID worker. The worker
consumes the retained proposal, edits only `calc.py`, runs the two public checks,
publishes a two-parent Git merge and completes its native task through the
existing owner claim/lease/fence/evidence path. Both original tasks finish at
revision four. STOP succeeds while the advisory inference receipt is deliberately
changed; tracked processes, owner validation callbacks, leases and waiters are
zero afterward. The fixture explicitly removes its observed published worktree
after STOP. Automatic worker crash recovery remains separate work.
