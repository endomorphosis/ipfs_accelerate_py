# Restore isolated admitted-run orchestration storage

The integrated upstream constructor omitted the signed per-run orchestration
path. Its retained native integration regression failed with a missing
`IPFS_ACCELERATE_AGENT_ORCHESTRATION_DIR` key. Without that override, the shared
catalog lookup can select an inherited account root or scan and migrate legacy
account-wide databases. The pre-fix failure is retained as nonqualifying evidence.

The repair restores an owner-private `runtime.state/orchestration` directory and
binds that exact path into the launch profile and signed manifest. It applies
inside the shared constructor without changing the new finite/inventory branches,
production defaults, resource thresholds or deadlines. Constructor setup leaves
the parent's environment unchanged.

All 11 focused integration executions pass with no failures, errors or skips and
unchanged consumed source/test pins. The suite exercises actual native owner child
START, heartbeat and STOP; both inherited and unset orchestration configurations;
refusal to scan account catalogs; manifest/profile environment binding and tamper
rejection; foreign/stale launch refusal; and existing context/configuration checks.
Each run used fresh isolated seal, key-store and scheduler paths. Their private
stores are excluded. The first failed control and the final 11 passes are not
combined into a passing total.

This is host integration evidence for a narrow restoration. Optional finite and
inventory execution branches were reviewed for environment constraints but were
not separately executed here. There was no Docker run, provider call, benchmark
completion, token score or transfer of a historical archive qualification.

The package contains exact commands, exits, XML/stdout/stderr, a reproducible
controller, before/final owner and test snapshots, and the patch. Only the root
manifest is excluded from its member inventory. External audit links identify
retained local evidence rather than missing package members. No auth store,
checkpoint, hidden verifier body or runtime input was exported or changed.
