## Full trial and temporary model pause

received official reward **0**. The supervisor ran for 326.949 seconds, below
its 840-second work cutoff, and failed before START with a `TypeError`:

native admission refusal or work-budget exhaustion. Planning produced two goals
and one task. Doctor returned a candidate and a verified local
`reject-control-preserve-safe` contract; it did not publish a repair or establish
whole-program correctness. There were no provider invocations. There is no
completed token-efficiency score or advantage claim.

agent execution phase was 328.966s; agent setup 199.457s, environment setup 6.487s,
and official verification 2.052s were measured separately. Original task inputs
were unchanged; worker cleanup returned 0 and the exact container was removed.
