formalization and retrieval one each. Reassembling the complete artifacts and
carrying their canonical JSON as inline objects removes 1,373 bytes of string
escaping. Replacement structure and guidance cost 624 bytes, leaving 749 bytes
of net savings. Every original evidence chunk and the exact original transport
reconstruct. Required constraints, unknown fields and source content remain.

The codec uses the existing 6,144-byte UTF-8 chunk contract and preserves finite
floating point retrieval scores. Valid unsupported body representations remain
literal. Invalid known chunk contracts are rejected. These checks establish
representation equality; they do not prove formalized program behavior.

The run used full indexed preparation, pinned Source384 inference, retained
`declared-contract@1` planning, admission, the ordinary worker/source boundary,
owner replay and cleanup. The intent autoencoder was explicitly disabled for
this profile; this is not qualification of every IR checkpoint. Source384
inference took 9.881 seconds and its retained checkpoint/configuration/inference
hashes matched the owner's currentness check. Inference was not rerun by replay.

Initial context took 14.889 seconds, planning 4.487, admitted context 3.813 and
the census 30.692. The complete owned Docker lifecycle took 226.284 seconds;
the outer execution step took 227.593. These timings are nested and from one
run, not comparative throughput evidence.

The capsule candidate made one authenticated preflight request: 4,096 response
bytes including 2,327 evidence bytes, zero supplied to a provider. Complete
capsule expansion was not verified in this public run. The inline candidate
keeps its complete evidence inline. Owner replay reproduced the complete

without independently replaying private input semantics.

The source session stopped with complete accounting, worker cleanup returned
zero, the allocated worktree was removed, admission was revalidated after
return, and the exact container was confirmed absent twice. No services or
resource limits changed. No hidden evaluator, solution or provider-response
reads were reported by the observation.

Zero planning or coding model generation calls ran. CLI system prompts, later
tool responses, repeated history, provider tokens and cost are unmeasured.
Official verification was disabled, task completion is false and no reward is
