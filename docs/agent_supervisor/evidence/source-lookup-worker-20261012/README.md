UID1001 helper processes reused one private native grant. The full exercise
recorded 13 requests: nine successes and four refusals, all delivered. Worker
JSON-plus-LF bytes totaled 20,904; primary pages accounted for 17,322, with the
largest envelope 2,588 bytes under the 32 KiB limit.

frame prefixes. Handshake/error traffic remains unknown; neither ledger is a
provider-token measurement. Matching owner-UID and unrelated worker-UID peers
were refused. Canonical and allocated edits invalidated source reads; exact
restore allowed a fresh read. Three private owner-path reads were denied.
The original grant was revoked, broker stopped, descriptor/socket removed and
both fresh owned containers removed. Product and runner hashes remained exact.
