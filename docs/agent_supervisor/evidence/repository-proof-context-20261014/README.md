The source binder joins the complete signed regular-file population to the
session's retained source, including the original omitted from the local theorem.
Extra files, unmatched empty directories, symlinks and gitlinks refuse. It
retains native and physical owners and distinguishes the original proof repository,
signed task-scope CID, complete local source-tree identity, session repository ID
and source-view SHA256. The latter is not relabeled as a Git tree. A fully signed
dirty candidate is supported; committed Git-tree equivalence is unqualified.

Compilation, expansion, retry and render snapshot caller/core/reference bytes,
check retained compiler policy and revalidate live proof and source currentness.
Closing proof eligibility follows callback-bearing native source observation;
a complete filesystem-only source fence follows it. An optional proof digest can
be deferred using the compiler's exact declared exclusion representation. Complete
conditions remain required even under budget pressure. Copies, old generations,
owner substitutions, changed policy, cache denial and reserved reference promotion
refuse. These are sequential checks rather than a filesystem writer lease.
