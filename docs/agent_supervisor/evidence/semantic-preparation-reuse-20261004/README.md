# Semantic preparation reuse controls

The datasets producer reuses immutable fact/edge identities within one capsule
or Merkle compilation, and avoids repeating identity serialization within one
Merkle verification. Stored-byte hashing, independent record reconstruction,
membership checks and layering remain. The supervisor still performs its second
cold scan/build and all fresh source/admission/proof gates.

Canonical IR collection rules retain at most 512 parsed exact-string JSON
pointers of at most 2048 characters. Other values use the original parser.
Only immutable syntax is reused; canonical payloads and proof results are not.

All 494 selected controls pass without skips: 271 semantic-state, 169 supervisor,
and 54 canonical identity/header checks including actual Z3 and public Bottle.
Expected pre-fix failures are retained. The first header control rerun omitted
the public-source fixture environment and skipped one check; the final complete
run supplies it and passes all 54. This corrected runner did not alter gates.

A diagnostic host pair built the same public-source scope through archived and
current graph owners in 40.771 and 37.629 seconds. All 6261 semantic blocks,
worker-context bytes and Doctor diagnostic bytes match. These are one host pair,
not a controlled Docker speedup. Reference injection exists only in this host
diagnostic; the production archive uses ordinary owners. Its earlier cProfile
run took 140.167 seconds under instrumentation and is not comparable to native
elapsed time. Capsule-only cold/warm measurements and the separate alternating
pointer derivation experiment retain their own limitations in the receipts.

No task completion, whole-program security, token advantage or production
qualification follows from these controls. Native results are retained separately.

The host timing commands bind the public source and script, but did not capture
producer hashes at each timing run. The provenance limitation is retained
explicitly; the byte comparison remains directly reproducible from the artifacts.
The later native archive also preserves an unrelated upstream training change;
training is disabled throughout this benchmark.
