# Retained decoder contracts and opt-in checkpoint authentication

This change authenticates existing registered checkpoint bytes for advisory
ready-root task contexts. It does not interpret tensors, instantiate models,
train, generate embeddings, authenticate remote Hub payloads or admit runtime.
Default version-1 contexts remain metadata nominations. Explicit version-2
contexts carry original checkpoint observations and reauthenticate on cold
reopen; an explicit consumer requirement refuses a downgrade. The native
catalog's authority fields remain unchanged and false.

The production helper preflights all exact selected file pins and aggregate
bounds, then streams read-only SHA256 with live descriptor/path identity checks.
The context wrapper closes all earlier task file witnesses after later tasks,
then repeats source/admission/native owner checks after checkpoint reads.
Canonical JSON joins distinguish integer/boolean substitutions in freshly
rehashed receipts. Cooperative endpoint checks do not establish atomic state or
lease files. Source AST/capsule construction and retained numerical-vector
reuse keep their existing separate contracts.

[Factual review](docs-fact-review.json) records the corrected cache, route-count
and vocabulary/output-budget distinctions against the actual retained reports.
Its document pins precede the final qualification and publication additions.

[Independent source review](independent-source-review.json) binds the four
changed/new implementation and test files. It records three real findings and
fixes: earlier files after later task authentication, source/native state after
long hashing, and strict inner JSON types. New native tests use actual signed
admission, pending contracts, readiness, source/retrieval/world consumers and
opaque byte fixtures. They do not qualify decoder inference. Controlled
boundary injections mutate actual source/native/file owners after genuine
operations; they are not positive-path production mocks.

assets. Recover and review their actual output schema and multi-input contract,

as separate metrics. The desired source cycle is legal text→legal_ir→legal text;
canonical deterministic decompilation alone does not recover original wording.

Decoder runtime qualification, dependent source successors, parallel leases,
review, merge currentness and durable completion remain separate gates. Reviewed
