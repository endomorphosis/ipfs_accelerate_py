# Provider-free semantic metadata census

The [census stop point](../../terminal_metadata_census.md) constructs both complete
coding inputs after current source/workspace/artifact and credential checks,
then returns a closed observation before provider discovery or allocation.
General planning and `llm_router` remain part of the live benchmark.

The combined fresh-seal regression passed **300 tests** with zero failures,
errors or skips. A final frozen-source runner/archive-policy rerun passed **63**,
and the final pure census qualification passed **30**. These focused counts
overlap the combined suite and must not be added as independent coverage.

The runner reports hashes/counts and fixed shared field names. Source text,
private paths, plan bodies, common values and unknown field names stay with the
current owner. The outer actual receipt retains declared public input names and
hashes for provenance. The byte-derived proxy is not the provider tokenizer, and representation
eligibility cannot authorize model use, omission, execution or completion.

The pure helper's initial source had one extra EOF newline. Its correction
preserves exact AST equality; original source hashes/tests/observations remain
recorded, followed by final-body tests and observations. The combined regression
ran during that whitespace correction, so the final 63-case rerun and separate
30-case pure qualification bind the final helper body explicitly.

Administrative public-task preparation uses an explicitly authored graph and
native signed admission/materialization, deterministic lexical indexing and the
actual pending-task context. It differs from a live input after LLM planning and
from the prior Source384 configuration. Public source processing by native owner
APIs is recorded separately from parent inspection and hidden evaluator reads.
Native prompts, catalogs, test seal databases and actual preparation logs remain
private; only closed metadata observations are suitable for publication.

A separately versioned live comparison must retain both phases, fixed transport
`@1` and the same reply schema. It must distinguish fixed operational controls
from exact matching of generated substantive inputs, preserve native identities,
and count all sessions/repairs/failures without double-counting cumulative usage.
Total token savings remain unmeasured.

The actual administrative source census selected four worker capsules across
two source groups. Complete wrapped input shrank **55,728 to 54,846 bytes**,
an 882-byte reduction (1.58%); the named proxy changed 13,932 to 13,712.
Exact restoration, actual Doctor/public suffix bindings, post-yield native
task/source revalidation and allocated-worktree cleanup passed. Provider/router
calls were zero. The owner observed a real local DuckLake projection receipt;
this does not qualify a live Quack gateway. No official task execution,
validation/reward, Source384 inference or LLM planning occurred in this scope.
The next live pilot gate is the genuine planned Source384 input census.
