# Public finite evidence in the native worker

The opt-in `supervisor-finite-public-context@1` route delivers the original
instruction, captured source, runtime assumptions, exact finite-domain rows,
counterexample, satisfied and residual requirements, and retained Python/Lean
receipts to the allocated worker. The bundle includes every referenced artifact,
including the generated Lean source and compiled object. It does not require
access to the owner's policy keys, database, or original observation directories.
The selected native Python and Lean executables must still be available at the
paths sealed in the tool policy; this is not arbitrary-host replay.

`publish_finite_public_context` consumes an already checked finite handoff and
the independent local admission. It revalidates the original observations before
export and signs the bounded immutable bundle. The public loader checks the
signature, task, complete instruction, source preimage, checked candidate,
domain, policy and every artifact hash. It reconstructs a temporary file-location
view using the existing datasets validator, then discards that view. The original
observation identities remain intact. Receipt reconstruction performs no new
checker execution and provides no independent attestation of physical execution.

`materialize_with_public_context` appends that read-only context after the native
dispatcher has expanded its semantic context. It preserves the original prompt
and instruction. The unchanged signed candidate runner checks the current Git
baseline and permitted edit; the native daemon still performs public validation,
publication and task completion. A received context is not a proof-admission,
execution or completion grant.

Run the authored finite qualification with installed native Python and Lean:

```sh
python -m benchmarks.agent_supervisor.container_coding.native_repository_finite_supervision \
  --output /absolute/new/run-directory \
  --python /absolute/native/python \
  --lean /absolute/native/lean \
  --public-evidence
```

The local 2026-10-02 run completed in **28.831 seconds** with zero LLM calls.
It retained the worker's public-context receipt, then independently checked the
published source, successor facts, cold reconstruction, stale-dispatch refusal,
and release of all run-owned processes and leases. Three integration tests also
passed, including fresh-process replay after the original private directories
were moved, missing/corrupt artifacts, wrong owners/tasks, altered requirements,
and forged authority declarations.

This qualifies a declared model-off finite profile. Its observed outputs, public
checks, Lean table scope and unavailable official benchmark reward remain
separate. General repository admission, learned interpretation and Terminal Bench
comparisons remain other backlog items.
