# Issued world packet retention and historical Terminal audit

This stage joins real issued repository packets to retained router inputs and
the Terminal input audit. It adds no historical-packet dispatch capability.
The original native task, signed observations, source generation, obligations,
write scope and validation requirements remain part of the packet. Missing world
authorities remain missing; the packet does not manufacture an accepted world.

The finite offline experiment reuses retained authored qualification fixtures
for native owner initialization and typed claims. It runs real source indexing,
Quack owner capture, signed public checks, a stdio MCP child, actual packet
issuance, router dispatch, artifact publication and the independent Terminal
audit. The provider response is scripted. It calls no live model or provider CLI,
loads no learned checkpoint and performs no training or live Terminal Bench run.

Generation one retains a failed public check, then an authored provider callback
uses a guarded full-file read and replaces the explicitly authored `answer`
function. The public check file stays unchanged. A stale packet cannot dispatch.
Generation two retains the passing check and issues a new packet. A newer native
failed observation invalidates that packet even after original source bytes
are restored. Neither public checks nor historical input verification complete
the task or establish unrestricted source semantics.

The four adopted cycle fixtures use the clean branch's established full-file
read and explicit local-symbol edit API. The sibling's later symbol-read tools
are not copied or credited as a narrow-read token improvement.

Successful invocations retain the complete packet and invocation artifacts in
an independently supplied private, canonical, owner-controlled directory. The
receipt binds their fixed invocation filenames, full byte counts and hashes.
The audit opens that selected root; it does not discover artifacts through a
worker workspace or activate a reconstructed packet. Missing, changed, foreign
or aliased artifacts remain unqualified.

The host opts in at the existing router call, while its allocated worker
checkout is the current directory:

```python
output, receipt = run(
    prompt=task_text,
    provider="codex_cli",
    model=model,
    timeout=timeout_seconds,
    max_output_tokens=output_limit,
    world_task_packet=issued_packet,
    world_packet_artifact_dir=artifact_root,
)
```

`issued_packet` must be the exact live `PreparedRepositoryWorldPacket` returned
by native issuance. The router checks its task, workspace, source generation and
intent observations before provider dispatch. Retention is optional; requesting
it requires a separately allocated private artifact root. Packet retention
failure prevents dispatch. Invocation retention failure after an attempted
provider call preserves that call's recorded outcome and native usage, while
marking retained evidence unavailable.

The host supplies its ordinary coding receipts and the same independently
selected artifact root to historical auditing:

```python
audit = collect_terminal_context_audit(
    state=native_audit_state,
    receipts=coding_receipts,
    workspace_root=owned_workspace_root,
    world_packet_artifact_root=artifact_root,
)
```

World-only replay needs no live state directory. A mixed population with missing
legacy state retains verified world inputs and reports incomplete population
verification. Retained JSON never becomes a live dispatch capability.

After owners and source sessions close, the experiment removes the original
checkout location and audits both retained complete inputs through the Terminal
collector's bounded child. Historical replay reconstructs the exact rendered
user input. It does not recheck native signatures, source/owner currentness,
tokenizer counts, provider framing, ingestion or provider response. All replay
proof, execution and completion flags remain false.

Root runs the experiment and tests under the independently pinned native
resource owner. Each run checks that its own admitted policy remains unchanged
and its lease releases; this does not claim a global configuration stayed fixed
between independently scheduled stages:

```text
python -m benchmarks.agent_supervisor.container_coding.terminal_world_packet_replay_experiment \
  --scratch-root /absolute/owned/scratch \
  --artifact-root /absolute/new-private-retained-root \
  --output /absolute/new/content-free-report.json
```

The retained artifact root must already exist, be empty, canonical and owned,
with mode 0700. Artifacts contain complete authored task/context inputs and are
private; the bounded report exports only hashes, descriptors, counters, checks
and declared source pins. Scratch storage reuses the bounded 128 MiB fixture
storage bound. Its world-only cleanup first requires closed native contexts and
a complete bounded census of owned, canonical, nonsymlink contents. Stable
nofollow directory descriptors permit adding owner-write only to owned
directories before cleanup; files and hardlinked file inodes receive no chmod.
Deletion uses the held root and censused child-directory descriptors. The root
name is never removed: an empty private root shell remains, recorded as
`held_root_contents_only/v1` with `private_fixture_root_removed: false`.
Qualification requires both that the original root remains bound and that its
held directory is empty. A replacement root or namespace change is incomplete
and its foreign contents remain untouched. Census refusals occur before the
permission step; later identity checks also refuse deletion. The previous
columns fixture owner is unchanged. Unavailable cleanup prevents qualification.
Output files are new private files
and never overwrite old results.
`validate_report` requires a FULL independent report hash and checks its finite
scope; it does not independently rerun native operations.

These observations qualify finite dispatch/retention/replay plumbing. Whole
session tokens, model-call avoidance, learned world prediction, task success and
token savings remain unmeasured.

The 2026-10-14 qualification passed 583 distinct current test cases, including
packet issuance and replay, live dispatch refusals, retention failures, mixed
audit populations and existing accounting/column/legacy regressions. The final
standalone experiment retained two successful authored invocations across two
source generations, ran three native signed checks and one real child MCP edit,
and refused both a stale source packet and a packet superseded by a newer native
observation. The independent historical audit reproduced both complete rendered
inputs after the owners closed and the original checkout moved. Provider
responses were scripted; this establishes no provider token savings.

`artifacts/world-packet-terminal-replay-20261014-01` in the parent workspace.

dependency pins, latest test populations, earlier failed attempts, resource
leases, artifact descriptors and the independently saved full report hash.
`measured-v03.json` records the final finite experiment and

admitted run released its lease and preserved its own pinned policy. An external

policy was repinned; the qualification did not reconfigure the shared scheduler.
