Twelve source-bound native restorations were observed; attempts and successful restores are counted even if a later owner construction fails.

## Next milestone: measured cost attribution

The source-level reduction did not yield a reliable end-to-end gain. The next bounded diagnostic should instrument phases before selecting another optimization. Static inspection still finds roughly 76 named source-file hash operations across four checks, plus two outer input-guard source checks. Each call performs four full reference-to-CPU byte comparisons and four comparisons across thirteen tensor chunks. Reference volume is only 30,688 bytes per 8D call or 181,088 per 384D call; this does not establish a bandwidth bottleneck. The actual recurrent forward counts are identical among routes.

The owned poll path has four child renewals and normally four durable scheduler writes, each with file and directory fsync. Root cancellation is checked; the benchmark cancellation helper does not renew the root. Including cancellation checks and the two remaining receipt reads gives fourteen inline scheduler transactions. Background auto-renewal is separate. These are static counts, not measured cost attribution; changing a training-weight format would not remove them. Checkpoint guard checks compare frozen structural snapshots; scheduler state has its own JSON encoding and persistence.

Create a separate source-pinned, bounded diagnostic run for phase wall/threadCPU spans, exact lock/fsync call observations, and CPU/CUDA operator traces. Keep every boundary and corruption refusal. Do not merge instrumented times with the frozen uninstrumented benchmark. Use the same owned budgets and <=120-second post-admission deadline, bounded traces, exact decisions/vectors, source/precision stability and zero cleanup. Then measure potential tensor-chunk coalescing or durable-renewal coalescing only with their cancellation/currentness and resource contracts preserved. Preserve four original guard boundaries and demonstrate any gain on balanced uninstrumented replay.
